1. 제품 개요

본 대쉬보드는 해상·육상·항공으로 이어지는 복합운송의 진행 상태, 예상 도착일(ETA), 구간별 지연, 외부 리스크, 대안 경로를 한 화면에서 확인하고 조치할 수 있는 리스크 점검 대시보드다. 기존의 이메일, 선사 사이트, 포워더 보고서, 뉴스 검색, 개별 엑셀 파일로 분산된 정보를 통합해 지연 인지부터 대안 확정까지 걸리는 시간을 단축한다.

핵심 가치는 다음 세 가지다.

현재 상황을 빠르게 파악한다: 전체 운송 리드타임과 구간별 상태를 단일 화면에서 보여준다.
지연 원인을 설명한다: ETA 변화와 관련된 운송 이벤트·뉴스·운영 리스크를 연결한다.
실행 가능한 대안을 제시한다: 선사서비스, 육상경로, 항공연결편을 비용, 시간, 위험 기준으로 비교한다.
2. 배경과 문제 정의
2.1 현재 문제
해상, 통관, 내륙운송, 항공 연결 정보가 서로 다른 시스템과 문서에 흩어져 있다.
계획 ETA와 최신 ETA가 혼재하며 어떤 날짜가 의사결정 기준인지 명확하지 않다.
지연을 발견해도 원인, 영향 구간, 예상 지연일, 담당자 조치가 연결되지 않는다.
최신 뉴스가 실제 운송 건과 직접 관련되는지 판단하는 데 시간이 많이 든다.
대안 경로 비교 시 운임, 리드타임, 환적, 용량, 통관 리스크의 단위와 기준일이 제각각이다.
의사결정자는 상세 데이터보다 현재 위험, 사업 영향, 요청 결정을 5분 안에 이해해야 한다.
2.2 해결할 사용자 문제

사용자는 B/L 또는 Shipment ID 하나로 화물의 현재 위치와 전체 ETA를 확인하고, 지연이 발생했을 때 영향을 받는 구간과 근거를 파악하며, 승인 가능한 대안을 즉시 비교할 수 있어야 한다.

2.3 제품 가설

운송 이벤트, ETA, 리스크 뉴스, 대안 경로를 동일한 Shipment ID와 기준시각으로 연결하면 다음 효과가 발생한다.

지연 탐지 시간이 단축된다.
ETA 예측 오차와 수작업 보고 시간이 감소한다.
긴급 운송과 불필요한 특송 전환이 줄어든다.
대안 승인에 필요한 근거가 표준화된다.
3. 목표와 비목표
3.1 제품 목표
운송 현황 조회부터 위험 조치 결정까지 5분 이내 완료
고위험 운송 건의 95% 이상을 목표 대응시간 안에 식별
ETA 평균절대오차(MAE)를 운영 기준 대비 20% 이상 개선
월간 수작업 보고 시간을 50% 이상 절감
대안 경로 비교 시 비용·시간·위험의 계산 근거 100% 추적 가능
3.2 비목표
실제 선복 예약, 운송 계약, 결제, 통관 신고를 직접 실행하지 않는다.
관세·FTA·제재 관련 최종 법적 판단을 자동 확정하지 않는다.
뉴스만으로 ETA를 임의 변경하지 않는다.
원천 시스템의 마스터 데이터를 대시보드에서 직접 수정하지 않는다.
초기 버전에서는 전 세계 모든 운송사 API를 지원하지 않는다.
4. 대상 사용자와 권한
사용자 주요 목적 필요한 기능 기본 권한
물류 운영 담당자 개별 화물 추적과 예외 조치 검색, 상세조회, 메모, 조치 등록 읽기·운영 입력
물류 매니저 지연 우선순위와 담당자 관리 필터, 배정, 승인 요청, KPI 읽기·승인 요청
구매·조달 담당자 운송비와 대안 비교 비용 비교, 견적 근거, 공급 영향 읽기
리스크·컴플라이언스 외부 이벤트와 규제 검토 뉴스 근거, 위험등급, 감사 이력 읽기·검토 의견
의사결정자 사업 영향과 승인사항 파악 요약 KPI, 위험 Top N, 승인 카드 읽기·승인
시스템 관리자 연동과 품질 운영 데이터 소스, 임계값, 권한, 로그 관리자

권한은 최소권한 원칙을 적용한다. 운임과 원가 데이터는 역할별 마스킹을 지원하고, 승인·임계값 변경·데이터 재처리는 감사 로그에 남긴다.

5. 핵심 사용자 시나리오
시나리오 A: B/L로 현재 운송 상태 확인
사용자가 B/L 번호를 입력한다.
시스템이 일치하는 운송 건과 중복 후보를 조회한다.
전체 계획 ETA, 최신 ETA, 지연일, 현재 구간, 마지막 이벤트 시각을 표시한다.
사용자가 구간별 계획일과 실적일을 비교한다.
데이터가 오래됐으면 갱신 지연 경고와 원천 출처를 표시한다.
시나리오 B: 고위험 화물 조치
위험 목록에서 위험점수와 예상 사업영향이 큰 운송 건을 선택한다.
시스템이 Trigger → Impact → Recommended Action 순서로 근거를 보여준다.
담당자가 대체 선사·항만·육상 경로·항공편을 비교한다.
승인 요청에 예상 추가비용, 단축일, 위험 감소폭을 포함한다.
승인 결과와 실제 조치·성과를 기록한다.
시나리오 C: 5분 의사결정 브리핑
전체 운송 KPI와 전주 대비 변화를 확인한다.
고위험 Top 5와 매출·생산 차질 가능성을 확인한다.
대안별 비용과 지연 회피 효과를 비교한다.
필요한 승인과 결정 기한을 확인한다.

9. 위험점수 모델

초기 위험점수는 설명 가능한 규칙 기반으로 시작한다.

총 위험점수 = 0.35×ETA 지연점수 + 0.25×이벤트 심각도 + 0.20×데이터 최신성 위험 + 0.10×경로 취약성 + 0.10×사업영향

정상: 0~39
주의: 40~69
위험: 70~100

점수는 0~100으로 정규화한다. 임계값이나 가중치 변경은 버전과 적용일을 기록한다. 머신러닝 모델로 전환해도 규칙 점수와 모델 점수를 별도로 보존해 결과를 재현할 수 있어야 한다.

10.2 데이터 품질 규칙
Shipment ID는 원천 간 연결의 기준키로 사용한다.
모든 시각은 원천 시간대와 UTC 값을 함께 보존한다.
ETA에는 생성시각, 모델·규칙 버전, 신뢰구간을 저장한다.
운임에는 통화, 환율 기준일, 유효기간, 세금·할증 포함 여부를 저장한다.
뉴스는 원문 URL, 발행일, 수집일, 관련 엔터티를 저장한다.
중복 이벤트는 shipment_id + event_code + event_time + location 기준으로 병합한다.
결측값은 결측 사유와 함께 저장하며 임의의 0으로 대체하지 않는다.

14. ROI 가설

연간효과는 다음 식으로 계산한다.

연간효과 = 보고시간 절감액 + 지연 회피액 + 긴급운송 감소액 + 체선·체화료 감소액

연간순효과 = 연간효과 - 구축비 - 연간운영비

ROI = 연간순효과 ÷ (구축비 + 연간운영비) × 100

초기 검증용 가정:

운영 담당자 보고·조회 업무 최소화
대시보드 도입 후 50% 절감
월 100건의 활성 운송 중 지연 10건
지연 건당 평균 손실과 긴급운송 비용은 확정값 사용

가정값은 실제값과 시각적으로 구분하고, 비용 근거가 없을 때는 산출 대기로 표시한다. PoC 종료 시 실제 사용 로그와 정산 데이터를 기반으로 ROI를 다시 계산한다.

17. 출시 수용 기준
검색 대상 운송 건의 95% 이상이 2초 이내 조회된다.

고위험 항목마다 Trigger, Impact, Action, 담당자, 기한이 존재한다.
대안 비교의 비용·시간·위험 산식이 재현 가능하다.
데이터 최신성 SLA 위반이 화면과 로그에 표시된다.
모바일과 데스크톱에서 주요 정보가 겹치거나 잘리지 않는다.
권한 없는 사용자는 운임 원가와 관리자 설정을 볼 수 없다.
승인·설정 변경·내보내기가 감사 로그에 기록된다.
파일럿 사용자 만족도 5점 만점 중 4점 이상을 달성한다.
